# Yield Summary 表格標題排序設計

## 目標

讓 `tool/Yield_Summary` 的 VSC CP TOOL 與 VSC FT TOOL 表格欄位標題可點擊排序，方便使用者快速檢視資料。

## 行為

- 第一次點擊欄位標題由小到大排序，再次點擊改為由大到小。
- CP 與 FT 各自保存目前排序欄位與方向；切換頁籤不清除。
- 重新擷取或重新貼上資料後清除該工具排序，回到資料原始順序。
- 數值欄位以數值比較，文字欄位以不分大小寫字串比較，空值固定置底。
- CP 排序完整 `transposedData.rows` 後仍只顯示前 50 筆。
- FT 排序 `ftSummaryData` 後重新繪製摘要表。
- 表頭顯示未排序、升冪或降冪提示，並使用可鍵盤操作的按鈕。

## 實作範圍

- `tool/Yield_Summary/js/cp_tool.js`
  - 建立 CP 排序狀態與表頭點擊處理。
  - 以排序後資料重繪表格。
- `tool/Yield_Summary/js/ft_tool.js`
  - 建立 FT 排序狀態與表頭點擊處理。
  - 以排序後資料重繪表格。
- `tool/Yield_Summary/css/style.css`
  - 維持表頭深色風格，補上排序按鈕的無障礙焦點與指標樣式。

不新增套件、不修改 API、不改變 Excel 匯出資料內容。

## 錯誤處理與驗證

- 缺失值不造成排序例外，並穩定排在最後。
- 排序只影響畫面資料順序，不改變原始資料與匯出來源。
- 以既有靜態頁面載入檢查與瀏覽器互動驗證 CP／FT 各欄位升冪、降冪、空值及重新載入資料流程。
