# T5830 解析完成後開啟產品選擇視窗

## 目標

使用者選取檔案後，先完成產品名稱與站點解析，再開啟產品／站點選擇視窗；解析期間顯示明確的處理中提示。

## 範圍

- 修改 `PipelinePage` 的選檔流程。
- 新增解析中狀態文字。
- 保留既有檔案格式驗證與錯誤處理。
- 新增測試確認解析完成後才開啟視窗。

## 行為

1. 選取有效 `.tar`、`.tgz` 或 `.tar.gz` 檔案後，先清除舊錯誤並顯示「正在解析產品名稱與站點…」。
2. 完成產品／站點群組建立及 metadata 初始化後，清除解析中狀態並開啟選擇視窗。
3. 找不到有效壓縮檔時，清除解析中狀態、維持錯誤提示，且不開啟視窗。
4. 不改變後續產品選擇、metadata 輸入與分析流程。

## 實作與測試

- 以既有 React state 管理解析中狀態，不引入非必要非同步 worker。
- 選檔測試驗證解析完成後顯示選擇視窗與解析提示不再存在。
- 執行 `PipelinePage.test.tsx` 及既有 T5830 回歸測試，再重新建置 `dist`。
