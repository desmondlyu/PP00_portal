# DL to Excel 合併匯出檔名設計

## 目的

讓使用者在合併儲存模式下自行定義輸出的 Excel 檔名，避免固定下載為
`datalog_merged.xlsx`。

## 範圍

- 修改 `tool\DL_to_Excel\index.html`。
- 不修改分開儲存 ZIP 的固定檔名。
- 不新增依賴或拆分現有單檔 HTML。

## 使用流程

1. 合併模式在「匯出模式設定」下顯示檔名輸入框。
2. 預設值為 `datalog_merged.xlsx`。
3. 切換至分開儲存模式時隱藏輸入框，切回合併模式時重新顯示。
4. 匯出時使用輸入值；空白回復預設值。
5. 移除 Windows 不合法檔名字元，並在缺少副檔名時補上 `.xlsx`。

## 實作與錯誤處理

- 合併匯出沿用現有 `XLSX.writeFile`，只替換輸出檔名參數。
- 顯示統計結果的 `outputName` 使用實際下載檔名。
- 若使用者輸入只含不合法字元，使用預設檔名，避免產生無法下載的檔案。

## 驗證

- 靜態檢查輸入欄位、模式切換顯示邏輯、檔名清理與 `.xlsx` 補全。
- 使用現有 sample 檔案確認合併匯出路徑仍存在，分開儲存 ZIP 命名未變。
