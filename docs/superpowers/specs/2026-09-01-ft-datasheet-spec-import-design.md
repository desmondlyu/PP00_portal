# FT 特性分析工具 DATASHEET_SPEC 匯入設計

## 目標

在「匯出無損公式 Excel」旁新增「匯入 DATASHEET_SPEC」按鈕，讓使用者可將先前匯出的無損 Excel 中的 `DATASHEET_SPEC` 分頁重新套用至目前已載入的特性資料。

匯入只更新規格，不取代目前的量測資料。規格套用完成後，系統必須重新計算判定、比率、圖表與統計總覽 A、B、C。

## 範圍

### 包含

- 在既有 Excel 匯出按鈕旁新增同高度、同風格的匯入按鈕。
- 讀取 `.xlsx`／`.xls` 檔案中的 `DATASHEET_SPEC` 工作表。
- 解析 `Item`、`Description`、`4Byte_Alignment`、`Group`、`Dummy_Rd`、`Min`、`Typ`、`Max`。
- 以完整比對鍵將新規格套用至目前資料。
- 重新計算 `Min`、`Typ`、`Max`、`Value_Spec_Ratio`、`Judge`、`Typ_Judge` 及衍生統計。
- 同步更新 Summary A、B、C。
- 顯示成功更新、未匹配與無效規格的結果。

### 不包含

- 不替換目前的量測資料列。
- 不從匯入檔案還原原始資料、產品、條件或使用者篩選。
- 不改變既有 `DATASHEET_SPEC` 匯出格式。
- 不新增伺服器或外部 API。

## 介面

- 新增按鈕文字：`匯入 DATASHEET_SPEC`。
- 按鈕放在 `匯出無損公式 Excel` 旁邊。
- 沿用現有按鈕 class、padding、字體與 disabled 狀態，使兩個按鈕高度一致。
- 使用隱藏檔案選擇器接收 Excel 檔案，避免破壞現有頁面排版。
- 匯入期間停用匯入按鈕，避免同時處理多個檔案。

## 比對與套用

### 完整比對鍵

每筆規格使用以下欄位組合比對：

`Item + Description + 4Byte_Alignment + Group + Dummy_Rd`

組成鍵值前，對欄位執行一致的空白清理與字串化處理，確保 Excel 儲存格格式差異不會造成不必要的未匹配。

### 規格值

- `Min`、`Typ`、`Max` 空白時，代表該方向沒有規格，套用空值。
- 可解析的數字套用為數值。
- 非空且無法解析為數值的規格視為無效；該筆保留目前規格並列入警告。
- 匯入檔案中完整比對鍵重複時，取消整次匯入並指出重複鍵。

### 未匹配資料

找不到目前資料對應項目的匯入規格不會新增資料列，也不會清除目前規格；該筆列入未匹配清單。

## 資料流程

1. 使用者點擊「匯入 DATASHEET_SPEC」。
2. 開啟隱藏的 Excel 檔案選擇器。
3. 讀取選取檔案並確認存在 `DATASHEET_SPEC` 工作表。
4. 驗證必要欄位與規格資料。
5. 建立完整比對鍵索引。
6. 若有結構錯誤或重複鍵，停止處理並保留原分析狀態。
7. 將有效且匹配的規格一次性套用至目前資料。
8. 對空白規格套用空值；對無效或未匹配資料保留原規格。
9. 重新執行既有衍生計算流程。
10. 更新資料表、圖表與 Summary A、B、C。
11. 顯示更新筆數、未匹配筆數與無效筆數。

## 重算規則

匯入後必須沿用目前既有的判定與統計邏輯，不建立第二套公式。重算內容包括：

- `Value_Spec_Ratio`
- `Judge`
- `Typ_Judge`
- 各 Group 與測試項目統計
- Summary A：Out of Datasheet Spec
- Summary B：Pass but Spec is Marginal
- Summary C：Recommended Specs

Summary B 維持目前規則：`Judge = Pass` 且 `Value_Spec_Ratio < 1.15`，亦即邊際裕度不足 15%。

## 錯誤處理

- 缺少 `DATASHEET_SPEC`：取消匯入並明確提示缺少工作表。
- 缺少必要欄位：取消匯入並列出欄位名稱。
- 完整比對鍵重複：取消匯入並列出重複鍵。
- 非數值規格：保留原規格並在結果訊息列出資料。
- 未匹配規格：保留原規格並在結果訊息列出資料。
- 檔案無法讀取或格式錯誤：取消匯入並保留原分析結果。

結構性驗證必須在狀態更新前完成；不可先更新部分資料後才回報錯誤。

## 部署限制

目前 repo 追蹤的是 `tool\CZ_dataset\index.html` 部署版，因此本次實作以該單檔為變更目標。不得引入外部 API 或新的執行環境依賴。

## 驗收條件

- 新按鈕與既有匯出按鈕視覺高度一致。
- 可從無損 Excel 讀取 `DATASHEET_SPEC`。
- 完整比對鍵可正確套用 Min、Typ、Max。
- 量測值與資料列不被匯入檔案取代。
- 匯入後 Ratio、Judge、Typ_Judge 自動更新。
- Summary A、B、C 顯示新規格下的結果。
- 空白規格可清除對應規格方向。
- 未匹配與無效資料不會污染原規格，且使用者可看見警告。
- 缺少工作表、缺欄位與重複鍵時，原分析結果保持不變。
