# 特性測試數據分析工具 (CZ Dataset Analysis Tool)

此工具用來分析 FT 特性資料，提供視覺化、統計化後的數據、圖表，並且適合提供給 JMP 作圖的資料結構

## 🆕 最新更新

🔄 新增新舊版別比對：載入舊版報告並自訂差異 % 門檻，自動找出「符合規格但改版落差過大」的風險項目，並可匯出 Excel！

🐛 修正 VIL／VIH 規格公式：依 VCC／VIO 與 Unit 正確換算，AC／DC 命名也能正常判定！

## 📋 功能簡介

### 1. 批次 Excel 上傳與解析
* 支援同時拖曳或選取多個特性測試 Excel 報告，請使用 PP22 提供的特性報告檔案，請留意 Excel 加密必須選擇 Public 避免無法解析
* 自動識別與解析包含 25°C、90°C、130°C、-45°C 等不同溫度分頁的測試數據。
* 自動讀取與整合測試條件中的 VCC、VIO、溫度、測量項目及對應的實測值。

### 2. 統計總覽面板 (Summary)
* **A. Out of Datasheet Spec (失效項目)**：自動彙總實測值或典型值判定為 `Fail` 的所有項目、測試電壓與溫度條件，便於快速定位失效點。
* **B. Pass but Spec is Marginal (邊際裕度不足)**：自動篩選出判定為 `Pass` 但量測值與規格極為接近的項目（邊際裕度小於 15%，即實測與規格比值 < 1.15），方便工程師提早預防潛在的良率風險。
* **C. Recommended Specs (建議規格)**：顯示目前規格與原始規格的差異，協助檢視放寬或收緊規格的影響。

### 3. 數據編輯表格 (Data Grid)
* **高密度分頁表格**：以高清晰度網格展示所有彙整後的測試數據與規格限。
* **即時搜尋與過濾**：可依項目名稱與描述搜尋，或多選 Group、溫度、Vcc、VIO、Judge、Typ Judge；VIO 篩選器與數值欄位都位於 Vcc 右側，沒有 VIO 時顯示「-」。
* **即時編輯與聯動計算 (Real-time recalculation)**：
  * 允許在網格內直接修改任何實測值 (Value) 或規格限制 (Min, Typ, Max)。
  * 任何修改都會立刻重新計算該行的判定 Verdict、比率 Ratio，並會以**黃色背景高亮標註該儲存格的修改狀態**。
  * 提供一鍵「重設變更」按鈕，隨時還原為原始 Excel 數據。

### 4. DATASHEET SPEC 規格頁籤
* 原始 Excel 匯入完成後，會新增第四個 `DATASHEET SPEC` 頁籤，完整呈現無損公式 Excel 中的 8 欄規格資料：`Item`、`Description`、`4Byte_Alignment`、`Group`、`Dummy_Rd`、`Min`、`Typ`、`Max`。
* 支援依 `Item`、`4Byte_Alignment`、`Group` 多選篩選；多個條件會同時套用，清空選取即可顯示全部規格。
* **Item 搜尋全選**：輸入關鍵字後按「全選」，只選符合的 Item，並取消其他勾選。
* 僅 `Min`、`Typ`、`Max` 可編輯；修改後按 Enter 或離開欄位即可套用。
* 支援數字、空白及依目前資料列的 `VCC`／`VIO` 公式，例如 `VCC*0.3`。空白代表清除該規格；無效輸入會拒絕並保留上一個有效值。
* 規格變更會同步更新數據編輯表格的 `SPEC`、`Ratio`、`Judge`、`Typ_Judge`，並重新計算統計總覽 A、B、C 與圖表資料。

### 5. 分析圖表預覽 (Charts)
* **自動 Group 分群頁籤**：支援以橫向分頁切換 All, Time, Normal Read, DTR read 等群組，自動將大批圖表分類呈現。
* **單項卡片排版**：每個測試項目一張卡片，寬螢幕每排 4 張（窄螢幕自動改 2／1 張），大量卡片分批顯示並標示「顯示 N / 共 M 張」。
  * X 軸為溫度，顏色代表 VCC／VIO 條件；Y 軸標示物理量與單位（例：`時間 (µs)`），可切換顯示單位（僅換算顯示）。
  * 同一項目跨溫度／條件／新舊版共用尺度；可切換「完整範圍／聚焦實測」、滑鼠滾輪縮放後按「重設尺度」還原。
* **規格與實測標記**：
  * **實心圓**＝新版實測、**空心圓**＝舊版 Baseline、**紅框**＝Judge Fail。
  * **Max** 紅色實線、**Min** 紅色虛線，兩者同時顯示；**Typ** 為可勾選的點線。隨 VCC 變化的規格以各條件短線表示。
  * 極小值以科學記號顯示（不再顯示成 0）；Tooltip 列出完整條件、規格、Judge 與 Δ／Δ%。
* **多選下拉式過濾器**：
  * 提供 `VCC`、`VIO`、`溫度`、`Judge`、`Alignment`、`過濾 Item` 六個獨立下拉式多選選單，各選單均支援「全選」與「清空」。
  * **搜尋與狀態記憶**：在 Item 下拉選單中輸入關鍵字過濾時，先前已經勾選的 Item 狀態會被穩定保持，不會因重新搜尋而重置。
  * **搜尋後全選**：Item 名稱與 Description 都可搜尋；按「全選」以搜尋結果取代勾選，無結果時保留原選取。

### 6. 無損公式 Excel 導出
* 支援將網頁上修改後的數據與規格匯出為 Excel 檔案。
* 導出的 Compare 工作表內含動態 Excel 巢狀公式（含 `IF`, `ABS`, `OR`, `UPPER` 等），自動動態鏈結到 `DATASHEET_SPEC` 工作表。
* 開啟導出的 Excel 檔案後，在 Microsoft Excel 中修改規格限制，判定 Verdict 與良率 Ratio 依然會自動隨公式即時重新運算。
* 匯出的 `DATASHEET_SPEC` 工作表會保留規格原始公式文字，方便在 Excel 中繼續編輯與追蹤規格來源。

### 7. 新舊版別比對（選填）
* 上傳頁並排兩個區塊：左側 **① 舊版 Baseline（選填）**、右側 **② 新版 Target（必填）**，皆可點擊或拖曳；先載入舊版再選新版即自動比對。分析後也可在「版別差異 (Δ%)」卡片載入、更換或移除舊版。
* 差異 Δ% = (新版 − 舊版) ÷ |舊版| × 100；舊版為 0 時改以規格範圍 |Max − Min| 計算（標示 Spec）。|Δ%| 超過門檻（預設 10%，可自訂）即為 **Risk**。
* **統計總覽**新增 Section D：依 Item 列出最差條件；**數據編輯表格**新增 Baseline、Δ、Δ%（可排序）、版本差異（可篩選），並自動縮小字級避免左右捲動；**圖表**以空心圓顯示舊版值，並可依「版本差異」篩選。
* 匯出 Excel：Compare 多 4 欄差異公式、Summary `B3` 可改門檻重新判定、Section D 摘要，以及 `Unmatched` 列出只存在單一版本的條件。
* 未載入舊版時，所有功能與匯出結果與原本相同。
