# CP DL Analysis · 晶圓電性分析

以 Wafer map 為中心的 Graph Builder。直接開啟 `index.html` 即可使用，無須伺服器、安裝套件或網路。原始量測資料只留在本機記憶體，不上傳、不寫入 localStorage。

## 操作

1. 匯入 CP DL 原始檔，也可拖曳檔案到畫面；首頁提供清楚標示的合成示範資料。
2. 左側搜尋參數，拖至圖表的 X、Y 或分組。也可點選參數後按左下角加入按鈕，或按軸區的「＋」。
3. Wafer map 固定保留，X／Y 使用實際 die 座標、等比例繪圖。拖入參數到 map 可切換著色；放大／縮小只改變視野。
4. 圖表的 X／Y 可各加入最多 6 個數值參數。散佈圖／關聯矩陣會顯示 X×Y 的獨立配對圖；直方圖與箱型圖則逐參數分開顯示，不混用單位。
5. 每張圖有自己的參數、分組及 Linear／Log 尺度，並可複製、刪除、切換全寬／半寬與高度。最多 12 張圖表。

## 選取與篩選

- 在 wafer、散佈圖或箱型圖框選，或在直方圖橫向拖出範圍，對應 die 會在所有圖上標亮。Shift＋框選可增加選取。
- **選取不會自動篩除資料**。按「只看選取」才會縮小統計母體；按「清除選取」只清掉標亮，按「重設篩選」才恢復全部資料。
- 左側「資料篩選」支援精確數值上下限與類別勾選；多個條件以 AND 組合。空白上下限代表不限，沒有勾選任何類別代表空集合。
- 篩選後 wafer 仍保留全體位置，以淡色顯示排除的 die。下方統計顯示目前資料與選取資料的比較。
- 展開 Die 資料可預覽前 200 筆。CSV 會匯出完整選取資料；無選取時匯出目前篩選後的資料。

## 統計定義

- 缺值不當成零；每張圖顯示有效 N 與被排除的筆數。
- Log 尺度排除零與負值。散佈圖的相關係數與趨勢線以當下尺度轉換後的有效配對計算，並標示對數轉換；常數資料相關係數顯示「—」。
- 箱型圖保留舊版定義：箱體為第 25／75 百分位數，中線為中位數，鬚線到最小／最大值，並疊加實際資料點。不是 1.5 IQR 離群值判定。
- 直方圖按目前 X 尺度等寬分組，Y 為 die count；橫向框選以完整 bin 選取。分組時以堆疊顯示，各類別顏色在同一檔案內固定。
- CAT 即使是數字，也視為類別。箱型圖分組超過 40 類時要求先篩選，不偷偷合併類別。

## 資料格式

第 6 行必須是欄位名稱，包含 `<X>` 與 `<Y>`，後續各行以空白分隔。例如：

```text
CP DL header 1
CP DL header 2
CP DL header 3
CP DL header 4
CP DL header 5
<X> <Y> <ISB> <ICC> <CAT>
-1 0 0.25 0.80 1
0 0 N/A 0.82 2
1 0 0.30 0.79 1
```

`***`、`N/A`、`NULL`、`nan`、`NaN`、`-` 為缺值。欄位數不一致的行會略過並提示；欄位名稱不可重複。無有效座標的紀錄不出現在 map，但其有效電性仍可參與統計。

一次載入一份檔案。重複 X／Y 座標會提示，map 重疊顯示、統計保留所有紀錄，不自動判斷或合併 wafer／重測資料。參數名稱及單位依原始欄位顯示，程式不猜測單位或規格上下限。

## 儲存與匯出

- 儲存版面下載 JSON，並在允許時於 localStorage 留一份設定。只包含圖表參數與尺度，不含原始數據、篩選條件或選取紀錄。
- 載入版面從 JSON 檔案還原；請先匯入量測資料，無對應的參數會略過。
- Wafer map 與每張子圖均可匯出 PNG。
- CSV 保留負數座標／數值；可能被試算表視為公式的文字會加上單引號，避免公式注入。

## 驗證

無依賴的核心測試：

```sh
node --test tool/CP_DL_Analysis/analysis.test.mjs
```

離線瀏覽器整合測試需在測試環境安裝 Playwright 與 Chromium，正式 HTML 不需要：

```sh
node tool/CP_DL_Analysis/browser.test.mjs
```

測試可用 `PLAYWRIGHT_MODULE` 指定 Playwright 模組絕對路徑、`CHROMIUM_PATH` 指定瀏覽器執行檔、`SCREENSHOT_DIR` 指定截圖目錄。涵蓋匯入、拖曳、多參數、選取與篩選、版面還原、PNG／CSV、缺值／Log、空集合與響應式畫面，同時確認沒有對外 HTTP 請求。
